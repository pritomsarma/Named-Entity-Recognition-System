PROJECT OVERVIEW

Understanding text through context.

Modern digital platforms generate enormous amounts of unstructured textual information. Extracting meaningful information manually from news articles, documents, reports, transcripts, and digital archives is difficult and time-consuming.

This project addresses that challenge using a Transformer-based Named Entity Recognition model built on BERT. Instead of relying purely on rules or keyword matching, the model learns contextual relationships between words.

The system performs token-level classification using the BIO tagging scheme and identifies entities such as people, organizations, locations, and miscellaneous entities.

CORE LOGIC

The language behind the model.

A

BIO Tagging

The model predicts a label for every token using the Begin–Inside–Outside sequence labeling format.

Barack B-PER
Obama I-PER
visited O
New B-LOC
Delhi I-LOC
B

Contextual Encoding

BERT processes tokens together and learns how the meaning of a word changes depending on its surrounding context.

H = BERT(X)
H Contextual token embeddings X Input token sequence
C

Token Classification

Each contextual embedding is transformed into classification logits representing possible entity labels.

Z = WH + b
ŷ = Softmax(Z)

MATHEMATICAL FOUNDATION

How the model learns.

Softmax Probability

P(yᵢ | xᵢ) = eᶻⁱ / Σ eᶻʲ

Converts classification logits into probabilities across possible entity labels.

Cross Entropy Loss

L = −Σ yᵢ log(ŷᵢ)

Measures the difference between predicted labels and the correct BIO entity labels.

F1 Score

F1 = 2PR / P + R

Balances precision and recall to evaluate entity extraction performance.

Every day, enormous amounts of unstructured text are generated through: * News articles * Reports * Documents * Broadcast transcripts * Social media * Digital archives Understanding important information inside this text manually is inefficient. For example: > "Barack Obama visited New Delhi to attend a meeting with the United Nations." A human can immediately understand that: ```text Barack Obama → PERSON New Delhi → LOCATION United Nations → ORGANIZATION ``` However, a computer needs to understand the context of each word. This project uses a Transformer-based language model to solve that problem. --- # 🧠 4. BIO TAGGING LOGIC Named Entity Recognition is performed using the BIO tagging system. | Tag | Meaning | | ------ | -------------------------- | | O | Outside an Entity | | B-PER | Beginning of Person | | I-PER | Inside Person | | B-ORG | Beginning of Organization | | I-ORG | Inside Organization | | B-LOC | Beginning of Location | | I-LOC | Inside Location | | B-MISC | Beginning of Miscellaneous | | I-MISC | Inside Miscellaneous | ### Example ```text Sentence: Barack Obama visited New Delhi. Barack → B-PER Obama → I-PER visited → O New → B-LOC Delhi → I-LOC ``` --- # 🔬 7. CORE MATHEMATICAL LOGIC ## Token Classification For every token, BERT produces a contextual embedding: ```text H = BERT(X) ``` Where: ```text X = Input Tokens H = Contextual Token Embeddings ``` Each token embedding is passed through a classification layer: ```text Z = WH + b ``` Where: ```text W = Learnable Weight Matrix H = BERT Hidden Representation b = Bias Z = Classification Logits ``` The probabilities are calculated using Softmax: ```text P(yᵢ | xᵢ) = exp(zᵢ) / Σ exp(zⱼ) ``` The predicted class is: ```text ŷ = argmax(P(yᵢ | xᵢ)) ``` --- # 📉 8. TRAINING LOSS The model learns by minimizing Cross-Entropy Loss. ```text L = - Σ yᵢ log(ŷᵢ) ``` Where: ```text yᵢ = Actual Label ŷᵢ = Predicted Probability L = Total Loss ``` During training: ```text Forward Pass ↓ Prediction ↓ Calculate Loss ↓ Backpropagation ↓ Update Weights ↓ Repeat ``` --- # 📊 9. MODEL EVALUATION The model is evaluated using standard NER metrics. ## Precision ```text Precision = True Positive / (True Positive + False Positive) ``` Measures how many predicted entities were correct. --- ## Recall ```text Recall = True Positive / (True Positive + False Negative) ``` Measures how many actual entities were successfully detected. --- ## F1 Score ```text F1 = 2 × Precision × Recall / (Precision + Recall) ``` The F1 Score provides a balance between Precision and Recall. --- # 💻 10.

Core Logic & Mathematics

Understanding the mathematical foundations powering the BiLSTM-CRF architecture.

1. BiLSTM Forward Pass

The BiLSTM computes hidden states by processing the sequence both forwards and backwards, capturing context from both directions.

$$ \overrightarrow{h}_t = LSTM(x_t, \overrightarrow{h}_{t-1}) $$ $$ \overleftarrow{h}_t = LSTM(x_t, \overleftarrow{h}_{t+1}) $$ $$ h_t = [\overrightarrow{h}_t ; \overleftarrow{h}_t] $$

2. CRF Score Function

The CRF layer calculates a sequence score by combining the emission scores (from BiLSTM) and learned transition matrices.

$$ S(X, y) = \sum_{i=1}^n P_{i, y_i} + \sum_{i=1}^{n+1} A_{y_{i-1}, y_i} $$

3. Log-Likelihood Loss

During training, we minimize the negative log-likelihood of the true tag sequence over all possible sequences.

$$ Loss = - \log \left( \frac{e^{S(X, y_{true})}}{\sum_{y' \in Y} e^{S(X, y')}} \right) $$

Critical Implementation

PyTorch implementation of the BiLSTM-CRF model initialization and forward propagation.

model.py
import torch
import torch.nn as nn
from torchcrf import CRF

class BiLSTM_CRF(nn.Module):
    def __init__(self, vocab_size, tagset_size, embedding_dim, hidden_dim):
        super(BiLSTM_CRF, self).__init__()
        self.embedding_dim = embedding_dim
        self.hidden_dim = hidden_dim
        self.vocab_size = vocab_size
        self.tagset_size = tagset_size

        # Embedding Layer
        self.word_embeds = nn.Embedding(vocab_size, embedding_dim)
        
        # Bi-directional LSTM
        self.lstm = nn.LSTM(embedding_dim, hidden_dim // 2,
                            num_layers=1, bidirectional=True, batch_first=True)

        # Maps LSTM outputs to tag space
        self.hidden2tag = nn.Linear(hidden_dim, tagset_size)
        
        # CRF Layer for sequence optimization
        self.crf = CRF(tagset_size, batch_first=True)

    def forward(self, sentence, mask=None):
        # Get BiLSTM emission scores
        embeds = self.word_embeds(sentence)
        lstm_out, _ = self.lstm(embeds)
        emissions = self.hidden2tag(lstm_out)
        
        # Decode using Viterbi algorithm through CRF
        prediction = self.crf.decode(emissions, mask=mask)
        return prediction

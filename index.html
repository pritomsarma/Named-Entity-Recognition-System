Abstract

Named Entity Recognition (NER) is a core subtask of Information Extraction in Natural Language Processing (NLP) that aims to locate and classify named entities mentioned in unstructured text into pre-defined categories such as person names, organizations, locations, medical codes, time expressions, quantities, monetary values, and percentages.

This project focuses on building a highly robust and scalable NER pipeline leveraging state-of-the-art Deep Learning architectures. By capturing both deep contextual semantic meanings through embeddings and sequence modeling, coupled with a Conditional Random Field (CRF) layer, the model accurately respects sequential tag dependencies (e.g., ensuring an I-ORG tag strictly follows a B-ORG tag). This hybrid approach guarantees highly accurate entity tagging across complex, ambiguous domains.

Architecture & Workflow

The system utilizes a pipeline that converts raw unstructured text into structured BIO (Begin, Inside, Outside) tags. The tokens are initially passed through an embedding layer (e.g., Word2Vec, GloVe, or BERT embeddings), encoded using a Bi-directional Long Short-Term Memory (BiLSTM) network to capture past and future context, and finally decoded using a CRF layer to model the sequence constraints.

Mathematical Formulation

The integration of a Conditional Random Field (CRF) on top of the BiLSTM outputs is essential for sequence labeling tasks. Instead of decoding independently, the CRF layer models the transition probabilities between tags.

1. Emission and Transition Score:
For a sequence of words $X = \{x_1, ..., x_n\}$ and a sequence of predicted tags $y = \{y_1, ..., y_n\}$, we define the score of the sequence as the sum of emission scores from the BiLSTM network and the transition scores from the CRF matrix: $$ s(X, y) = \sum_{i=1}^n P_{i, y_i} + \sum_{i=0}^n A_{y_i, y_{i+1}} $$ Where $P_{i, y_i}$ is the emission score of tag $y_i$ for word $x_i$, and $A_{y_i, y_{i+1}}$ is the transition score from tag $y_i$ to $y_{i+1}$.
2. Sequence Probability:
The score is then transformed into a probability distribution over all possible tag sequences $Y_X$ using a softmax function over the sequence space: $$ p(y|X) = \frac{e^{s(X, y)}}{\sum_{\tilde{y} \in Y_X} e^{s(X, \tilde{y})}} $$
3. Log-Likelihood Loss:
During training, we minimize the negative log-likelihood of the correct tag sequence: $$ \mathcal{L} = - \log(p(y|X)) = \log \left( \sum_{\tilde{y} \in Y_X} e^{s(X, \tilde{y})} \right) - s(X, y) $$

Critical Code Implementations

Below is a representative PyTorch implementation snippet defining the core neural network architecture for the NER task, specifically mapping the sequential hidden states into the required classification space before CRF processing. 

import torch
import torch.nn as nn

class BiLSTM_CRF_NER(nn.Module):
    def __init__(self, vocab_size, tagset_size, embedding_dim, hidden_dim):
        super(BiLSTM_CRF_NER, self).__init__()
        self.embedding_dim = embedding_dim
        self.hidden_dim = hidden_dim
        self.vocab_size = vocab_size
        self.tagset_size = tagset_size

        # 1. Embedding Layer
        self.word_embeds = nn.Embedding(vocab_size, embedding_dim)
        
        # 2. BiLSTM Encoder
        self.lstm = nn.LSTM(embedding_dim, hidden_dim // 2,
                            num_layers=1, bidirectional=True, batch_first=True)
        
        # 3. Linear Layer mapping to tag space
        self.hidden2tag = nn.Linear(hidden_dim, tagset_size)
        
        # 4. (Implementation of CRF layer usually follows here)

    def _get_lstm_features(self, sentence):
        """Pass input through Embeddings and BiLSTM"""
        embeds = self.word_embeds(sentence)
        # Sequence encoding
        lstm_out, _ = self.lstm(embeds)
        # Emission scores mapping
        lstm_feats = self.hidden2tag(lstm_out)
        return lstm_feats

    def forward(self, sentence):
        """Forward pass predicting the best tag sequence"""
        # Get emission scores from BiLSTM
        lstm_feats = self._get_lstm_features(sentence)
        
        # Decoded using Viterbi Algorithm (Assuming CRF module is applied)
        # score, tag_seq = self.crf_layer.decode(lstm_feats)
        # return score, tag_seq
        return lstm_feats
